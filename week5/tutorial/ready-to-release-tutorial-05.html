Exercise 1

Objective

Download, combine and wrangle the election data so it is ready for mapping!.

We will need this for the second exercise.

1.1 Load the packages you need
library(tidyverse)
library(sf)
1.2 Import the election data
url = "https://results.aec.gov.au/27966/Website/Downloads/HouseDopByDivisionDownload-27966.csv"

election_data <- read_csv(url, skip = 1)
1.3 Wrangle your data so we only keep the winners from the election.
election_data = election_data |>
  filter(CalculationType == "Preference Count" &
    Elected == "Y" &
    CountNumber == 0) |>
  mutate(DivisionNm = toupper(DivisionNm))
Check your understanding of the code

  • Why do we filter by Elected == Y?

  • Why do we filter by CountNumber == 0?

  • What does the toupper() function do and why do we need it?

Answers

  • We want to select winning candidate only

  • This is preferential voting, so we will end up with repeat rows for each count. As there are different numbers of candidates in each electorate a solution that works for everywhere is CountNumber == 0. There are other ways to do this - but this piggybacks off the code from class.

  • The toupper functions makes everything upper case (e.g. hi to HI). We use this as small differences in naming conventions are taken care of (e.g. MC vs Mc). When we join with the map data later we are less likely to have small issues with naming.

1.4 Read the map data using the code below.
Important

We do not use read_csv here. We need to use read_sf as this is a map.

vic_map_path = "data/vic-july-2021-esri/E_VIC21_region.shp" 
vic_election_map <- read_sf(here::here(vic_map_path)) |>
  # to match up with election data
  mutate(DivisionNm = toupper(Elect_div)) |>
  sf::st_simplify(dTolerance = 100)
Tips for dealing with polygons

Why might I want st_simplify? Sometimes you don’t need all the fine details, particularly if the map is zoomed out. This function will simplify the number of vertices in the polygon drawn.

Read about it using the help menu and suitable values for setting dTolerance.

1.5 Combine the election data with the election boundaries.
vic_election_map = vic_election_map |>
  left_join(election_data, by = "DivisionNm")
Do you remember how joins work?

You can refresh how to combine to data sets together by reviewing the tidyverse cheat sheet. Try some toy examples yourself, ask your tutor or get some guidance from Generative AI.

Draw a map of Victoria and colour the electorate districts with the political party that won that district in the 2022 federal election.

2.1 Draw a map that looks like below.

To do this we need to use mapping functions that work with ggplot2.

  • The function geom_sf is used to define the aesthetics of how to plot the map.

  • The function coord_sf is used to define the coordinate range of the plot.

Hint 1

Hint 2 
vic_election_map |>
  ggplot() +
  geom_sf(aes(geometry = geometry, fill = PartyAb), color = "black") + 
  coord_sf(xlim = c(???, ???), ylim = c(???, ???)) +
Solution 
vic_election_map |>
  ggplot() +
  geom_sf(aes(geometry = geometry, fill = PartyAb),
    color = "white"
  ) +
  coord_sf(xlim = c(144.8, 145.2), ylim = c(-38.1, -37.6)) +
  scale_fill_manual(values = party_colors) +
  ggtitle("Winners of Australian Federal Election in 2022",
    subtitle = "Victoria"
  )

Exercise 4: Extend yourself!

Repeat exercises 1 and 2 above but for all of Australia.

There will be a few things you should watch our for:

  • The increase in map size will make reading the files and plotting the data much slower compared to Victoria. So be sure to use st_simplify().

  • You may also encounter an odd error with this map where you need to use st_valid() to redraw the polygons correctly.

  • For the whole of Australia there may be other parties for which we have yet to download the colours.

  • There may also be some small differences in how the electoral divisions are named. You may need to handle some edge cases.
